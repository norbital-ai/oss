# `@norbital-ai/config`

Shared configuration consumed by Norbital packages. It has no runtime code or build step.

See the [configuration overview](./docs/README.md) for ownership and usage boundaries.

## Exports

- `@norbital-ai/config/svelte.json` — common TypeScript configuration for Svelte packages and apps

```json
{
	"extends": "@norbital-ai/config/svelte.json"
}
```
