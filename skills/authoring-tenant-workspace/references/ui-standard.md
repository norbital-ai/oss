# Template UI standard

Review checklist for every page. Each line names its rule's home; `check/*` names are the lints that enforce it.

1. **Homes:** every field, figure and list sits in exactly one tab, the one whose concern it serves; the record's own tab holds identity only; derived figures sit with their concern; no setting at two scopes (`product-ux` Structure).
2. **Names:** labels in the user's words; no bare abbreviation, code or enum value as a label; domain terms explained in `help` / `description`; one name per concept (`product-ux` Names).
3. **Scaffolds and chrome:** `AppShell` (icon, 1–3 word title never repeating the workspace name, ≤90-character description ending in a period) for lists, boards, dashboards, reports and portals; `RecordShell` for any single record, settings included. Primitives own their chrome ([app-structure.md](app-structure.md)).
4. **One concern, one scroll:** at most one `Table` or `Board` per view (`check/single-data-view`); no `AppShell variant="full"` wrapping a single `Table` (`check/app-shell-inset`); one scroll owner per axis (`check/scroll-ownership`).
5. **Navigation and selection:** `Tabs` for views and sub-reports; view switchers in `toolbar.trailing`; `AppShell.actions` only for shared scope; a list paired with a picture of the same records shares one selection ([app-structure.md](app-structure.md), Rows and linked views).
6. **Forms:** compact grids, scalar fields before `wide`, no one-field sections, parent ref hidden when scoped, context keys locked, dependent pickers scoped, no server-derived inputs, `<Field>` kept for redacted fields ([app-structure.md](app-structure.md), Record hub and forms).
7. **Kinds and tables:** `Show` / `Field` kinds (`date` medium, `instant` medium + short time, `money` `CODE 1,234.00`, trimmed decimals, empty `—`); `StateBadge` for states, `Badge` for enums. Controlled tables declare `kind`, `align: 'end'` on numbers and one `money` column per amount (`check/controlled-table-kinds`).
8. **Controls:** visible labels, never placeholder-only; no raw `<select>` (`check/raw-select`); sizes from the parent layout (`check/self-sized-control`).
9. **Surfaces and behaviors:** `<Surface>` and semantic tokens, no `dark:` or raw colours; `<Image>` for record images; workspace `theme` in `src/+workspace.ts`; custom widgets composed from `@norbital-ai/ui/behaviors` and registered with `register_control` ([behaviors-and-composition.md](behaviors-and-composition.md)); typography roles only (`check/typography-tokens`); Lucide `<Icon>` only (`check/raw-unicode-icons`).
10. **CTAs, summaries, charts:** at most one `Button variant="brand"` per view; KPI strips of 4–5 figures with empty ones omitted; charts in ~16–20rem panels, never `<Bound size="viewport">` (`check/chart-viewport`).
11. **States, Save, language:** `EmptyState` and skeletons; one Save per view, one entity edited in place; catalogue keys for all visible text in every declared language (`check/untranslated-text`); verified at desktop and phone widths in light and dark themes.
