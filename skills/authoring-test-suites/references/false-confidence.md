# False confidence

For each case, name the production edit that makes it fail. If removing the rule leaves it green, it does not cover the rule.

1. **Refusal before the subject ran.** A malformed fixture fails early and a broad catch reads as refusal. Include an admitted caller through the same route; assert refusal and no write; distinguish denial from exception.
2. **Fixtures for a system that does not exist.** Check a fixture against the declaration and real producer. For external payloads use the vendor's published shape; include a wrong-shape case when that defect matters.
3. **A projection the query never selected.** A double can supply a field the read's `fields` omit. Run the real query against a database, with an opposite case.
4. **Absence instead of presence.** Verify a positive artifact, such as the recorded request or changed row.
5. **A checker never challenged.** Exercise a new rule on a representative defect.
6. **Wiring instead of behaviour.** `toHaveBeenCalled()` proves dispatch. Assert state, value, refused input or recorded order.
7. **A second copy of the rule.** A test reimplementing grants or calculation stays green while runtime changes. Drive the production path with compiled source bindings and real identities.
8. **Plausible emptiness.** Empty can mean a correct filter, failed transport, missing authority or a swallowed error. Pair it with a populated case; render loading and failure apart from empty.
9. **Tests keeping dead code alive.** A helper whose only caller is its test is not coverage. Remove it.
10. **A green command that never ran the gate.** Check exit code, include globs, skips and pipes. A permanently skipped case is not evidence.
11. **A complete-looking partial page.** A page is not the collection and a filtered list is not the relation. Use data beyond the boundary. Assert unloaded records survive edits and a full read completes or reports its bound.
12. **A receipt ignored.** Scanning fake state for a match can hit an earlier run. Follow the receipt's identity.

Probes complement tests: exercise a built artifact and inspect the persisted result. A plausible screenshot is not a successful write. Keep sensitive seed content out of transcripts and reports.
