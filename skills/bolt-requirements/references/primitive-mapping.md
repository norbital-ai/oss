# Primitive mapping

Default business-to-Bolt constructions (use unless a requirement breaks it):

- **Data & lifecycles:** lifecycle → `state` + `locked` constraint; same-stream variants → one polymorphic model (`kind` + union custom datatype/shaped `json`); effective-dated facts → `period` + `no_overlap` + successor writes; authoritative balances/accounting → append-only `locked` ledger with offsetting entries; structured parent-bound values → built-in kind, `custom_field`, or shaped `json` (owned child model only for FKs/row queries); supported variation → validated runtime config model; numbering → `seq`; child totals → `sum`/`count` roll-ups; prefer terminal states over deletion.
- **Rules & money:** `money` + Effect `BigDecimal` derived once in write pipeline (never recomputed in UI); lock committed documents & snapshot line prices; row invariant → `check` constraint, cross-row → callback refusal, authority → policy grant.
- **Work & screens:** schedules/events/operations → automations (with `rest` on workspace crons); judgement → `sys_2.infer`/`sys_1.decide`; unattended multi-step work that files its own results → `sys_2.task`; reports → `aggregate`/roll-ups (never regroup wide sets in memory); shared pure math → `src/lib`; screens → `AppShell` + shared views (`$derived`, catalog copy, one scroll owner).
- **People & external:** internal auth → source policies + teams; approvals → verdict `ctx.approve`; customers/vendors → external members scoped to `actor.party`; anonymous forms/chat → public app / public envoy; external systems of record → sync-first into local models (`+<sync>.sync.ts` `read`/`write`, signed `webhook.verify`/`handle`) so apps/reports/automations read models only (direct on-demand live reads, never polling, only on explicit user opt-out or when full continuous sync is unnecessary and fresh values are needed only at view time or report/agent snapshots; follow `integration-sync`), explicit operational calls via `ctx.request`, MCP, `+secrets.ts` / per-instance `credential`.
- **Anti-patterns:** storing derived numbers, computing money in >1 place, exposing raw UUIDs/IDs, raw untranslated text, manual `refetch`/polling, polling or reading external systems of record directly from pages/reports/automations instead of synced models, mutating committed history, creating a model only to display a nested value.
